## Key Features & Tasks Overview

### Part 1: Introduction to JavaScript

* **Task 0 (First Script):** External script execution logging student details in the developer console and showing an alert message (`Hello, JavaScript World!`).
* **Task 1 (Variables & Operators):** Demonstration of `string`, `number`, and `boolean` data types, arithmetic operations, and string concatenation in console logs.

### Part 2: DOM Manipulation

* **Task 2 (Changing Content):** Dynamic text updating of HTML paragraphs upon button click.
* **Task 3 (Changing Styles):** Toggle background colors and adjust text font sizes of elements programmatically.
* **Task 4 (Creating & Removing Elements):** Add new list items (`<li>`) or remove existing ones dynamically from a container (`<ul>`).

### Part 3: Events

* **Task 5 (Mouse Events):** Interactive hover container reacting to `mouseover` and `mouseout` events.
* **Task 6 (Keyboard Events):** Real-time text display updating dynamically using `keyup` listeners.
* **Task 7 (Calculator):** Fully functional basic calculator supporting addition, subtraction, multiplication, and division with error handling for division by zero.

### Part 4: Mini Project — Interactive To-Do List

* **Task 8 (To-Do App):** Interactive task manager featuring:
* Input form with title and description fields.
* Temporary state storage in a JavaScript array.
* Mark-as-completed functionality (line-through strike effect).
* Task deletion and responsive UI matching assignment wireframes.
